## 🛠 Getting Started

### Prerequisites
- Node.js 18+
- Firebase Project
- Google AI API Key (Gemini)

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment variables in `.env`:
   ```env
   GOOGLE_GENAI_API_KEY=your_api_key
   ```
4. Run the development server: `npm run dev`
