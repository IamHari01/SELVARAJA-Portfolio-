# **App Name**: ARCHETYPE: SELVARAJA

## Core Features:

- Generative Ambient Intelligence Background: A living shader-based neural environment that uses AI to morph and react based on user scroll velocity and viewport position.
- Orbital Skill Constellation: An interactive WebGL orbital system visualizing expertise nodes through reactive glowing clusters and spring-physics link systems.
- Neural Interaction Telemetry: High-fidelity user journey tracking and contact lead capture system integrated with Firestore.
- Research-Grade Glass Portals: A project display system featuring deep glassmorphic cards with iridescence, Fresnel edge-glow, and translucent backdrop filters.
- AI Architecture Chat Terminal: An embedded LLM-powered command line tool that functions as a technical persona, providing deeper reasoning into system design decisions.
- Magnetic Fluid Interaction System: CTA components utilizing cursor-reactive liquid distortions and energetic pulse wave triggers.
- Cinematic State Synchronization: A global motion system that ensures all transitions maintain 60fps performance and physical persistence.

## Style Guidelines:

- Primary Color: Vibrant Electric Blue (#4D9BFF), evoking advanced computation and light emission.
- Background Color: Obsidian Void (#0B0E11), a deeply desaturated blue-black that maximizes the luminosity of UI components.
- Accent Color: Hyper-Cyan (#1AFFFF), an analogous hue for interactive elements and active status indicators.
- Font Recommendation: 'Inter' as a pairing of headlines and body text. Use ultra-tight kerning and heavy weights for hero typography to create a machined, objective aesthetic.
- Code Font: 'Source Code Pro' for the macOS-inspired terminal footer and project technical specifications.
- Minimalist single-page architecture using high vertical white space (spatial rhythm) and deep Z-axis layering for glass components.
- Spring-based cinematic motion; all reveal transitions must include a subtle 3D perspective rotation and inertia-based scroll reveal.
